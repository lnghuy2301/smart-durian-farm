# Bộ nhận diện chính thức đã chọn

Người dùng xác nhận Smart Durian — Brand Kit v1.0 / Durian Connect ngày 2026-10-08 để dùng cho toàn dự án.

Bộ kit đã chuyển nguyên vẹn đến [assets/brand/Smart_Durian_Brand_Kit/](../../../assets/brand/Smart_Durian_Brand_Kit/), làm nguồn chung cho web, mobile và tài liệu. Thư mục cũ `docs/frontend/brand/Smart_Durian_Brand_Kit/` không còn là nơi lưu tài nguyên.

- [Quy ước tổ chức và tích hợp vào code](../../../assets/brand/README.md).
- [README gốc của bộ kit](../../../assets/brand/Smart_Durian_Brand_Kit/README.md).
- [Brand guide HTML](../../../assets/brand/Smart_Durian_Brand_Kit/05_Guidelines/brand-guide.html).
- [Design tokens dùng chung](../../../assets/brand/Smart_Durian_Brand_Kit/05_Guidelines/design-tokens.json).

Chỉ đặt ghi chú tích hợp frontend ở đây; cập nhật tài nguyên thương hiệu tại nguồn chung. Chưa code giao diện, tải font hoặc cấu hình app trong đợt sắp xếp này.
